# 공통 Definition of Done

이 문서는 모든 역할의 완료 판단과 인수인계 기준이다. [공통 지침](../../AGENTS.md)과 해당 역할의 완료 조건을 함께 적용한다. 작업에 해당하는 조건만 검증하고 전체 체크리스트를 매번 출력하지 않는다.

## 완료 판단

| 기준 | 확인할 내용 |
|---|---|
| 산출물 | 승인된 범위의 파일·명세·검증 결과가 존재하고 경로 또는 링크로 확인 가능하다. |
| 요구사항 | 수용 기준과 정상·예외·경계 조건을 충족하며 제외 범위를 침범하지 않는다. |
| 검증 | 수행한 명령·대상·기준 상태·결과와 미검증 항목·이유를 구분한다. 최종 변경에 결과가 유효한지 [검증 신선도 절차](automation.md#검증-신선도)로 확인하며, 확인하지 못한 최종 상태를 검증 완료로 보고하지 않는다. |
| 변경 영향 | 기존 사용자 변경을 보존하고 관련 없는 코드·설정·외부 서비스 변경이 없음을 확인한다. |
| 인수인계 | 다음 담당 역할, 산출물, 확정 결정, 미확정 사항과 필요한 후속 작업이 명확하다. |
| 문서 | 실제 구현과 관련 원본 문서가 일치하며 중복 원본을 만들지 않는다. 중요한 기술 결정은 필요 시 ADR로 남긴다. |
| 위험 | 미해결 문제·차단 요인·승인 대기와 후속 담당자를 명시한다. 필수 조건이 남으면 완료로 처리하지 않는다. |

## 작업별 검증

- 문서·지침: 내용 충돌, 상대 링크, 책임·승인 경계, 기존 규칙 누락, diff와 공백 오류를 확인한다. 코드에 영향이 없다면 빌드·테스트 미실행 이유를 밝힌다.
- Android 구현: 변경 코드 검토와 관련 단위·통합·UI 테스트, 가능한 빌드·Lint를 수행한다. UI 변경은 필요한 상태·테마·접근성·화면 크기를 확인한다.
- Backend 구현: Migration 재현, 제약조건, 사용자 간 격리·RLS, 데이터 계약을 검증한다. 로컬 검증과 원격 적용을 구분하고 실제 적용은 승인된 환경에서만 수행한다.
- 디자인: 요구 화면·상태, 토큰·컴포넌트 일관성, 구현에 필요한 규격을 확인한다. Figma 작업 완료와 Compose 구현 완료를 구분한다.
- CI·릴리스: 대상 커밋과 실행 결과를 연결한다. 릴리스 작업에 한해 빌드·설치·아티팩트를 검증하며 사용자 승인 전 배포하지 않는다.
- 테스트 소스가 없는 `NO-SOURCE`, 실행되지 않은 검사, 다른 커밋의 CI 성공은 현재 동작 검증 통과로 간주하지 않는다. 실행할 수 없는 검사는 이유·영향·후속 방법을 남긴다.

## 인수인계와 협업 기록

작업에 필요한 역할만 참여한다. 인수인계는 다음 정보를 간결하게 전달한다.

- 작업 식별자와 수신 역할: 실제 Issue가 있으면 사용하며 번호를 만들지 않는다.
- 산출물 경로·링크와 적용 기준 버전 또는 커밋(있는 경우).
- 확정된 결정과 수용 기준별 검증 결과.
- 남은 결정·차단 요인·필요한 승인·다음 작업 및 담당 역할.

역할 간 중요한 요청, 요구사항·설계 충돌, 데이터 계약·디자인 시스템·아키텍처 변경, 차단 문제만 협업 기록 대상으로 삼는다. 사소한 수정과 대화 원문은 저장하지 않는다.

협업 기록은 요청 1~3문장, 답변 1~3문장, 결정 1~2문장을 기본으로 같은 주제의 기존 기록을 갱신한다. 연결된 원본과 후속 작업을 남기고 해결 상태를 갱신한다. 기록 도구·위치가 아직 구성되지 않았거나 쓰기 승인이 없다면 완료 보고에 전달할 요약과 기록 대기 상태를 남긴다. 기록을 위해 외부 공간을 임의 생성하거나 전송·저장 성공을 가정하지 않는다.

## 완료 보고

- **결과:** 완료 / 부분 완료 / 차단. 승인된 작업 범위를 기준으로 판단한다.
- **산출물:** 생성·수정한 파일과 관련 링크.
- **주요 변경:** 무엇을 왜 변경했는지, 필요한 아키텍처 고려사항.
- **검증:** 수행한 검사와 결과, 미실행 항목과 이유, 확인된 사실과 가정.
- **후속 작업:** 남은 위험·제약·의존성과 다음 담당 역할. 불필요하면 생략한다.

일반 구현 작업의 완료에 병합·배포를 자동 포함하지 않는다. 요청 범위가 적용·릴리스까지라면 해당 단계가 남은 상태를 명시한다.
